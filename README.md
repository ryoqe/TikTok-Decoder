# 🎬 TikTok Decoder & Repair Tool

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![FFmpeg Required](https://img.shields.io/badge/ffmpeg-required-green.svg)](https://ffmpeg.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**TikTok Decoder** — это автоматизированный инструмент для анализа и полного восстановления видеофайлов, созданных с помощью обходов кодировщика TikTok («ломание кодировщика», 120 FPS glitch, PTS scaling, `-itsscale`, подмена метаданных MP4). 

Такие видео создаются для завышения битрейта и обхода сжатия TikTok, но на ПК (в VLC, Premiere, Vegas, CapCut) они лагают, вызывают просадки звука или содержат десятки тысяч поврежденных мусорных пакетов в конце файла. Данный инструмент вычищает поврежденную структуру, выправляет скорость и конвертирует видео в плавно воспроизводимый **H.264 MP4 (60/120 FPS)**.

---

## 📌 Разбор эксплоитов TikTok и проекты на GitHub

TikTok при обычных условиях режет видео до 1080p 60 FPS с битрейтом 2–4 Мбит/с. Авторы контента используют модификацию медиа-контейнера MP4, чтобы обойти эти ограничения.

### Упомянутые проекты на GitHub:
* 🛠️ **[ut0ku/120fps-method](https://github.com/ut0ku/120fps-method)** — скрипт подмены метаданных контейнера `stts` и `timebase`.
* 🛠️ **[LuisAlves10/TikTok-FPS-Compression-Bypasser](https://github.com/LuisAlves10/TikTok-FPS-Compression-Bypasser)** — инструмент прямых манипуляций с атомами `mvhd` и `mdhd` MP4.
* 🛠️ **[EditingSource/EN-TikTok-60FPS](https://github.com/EditingSource/EN-TikTok-60FPS)** — GUI-приложение с нейросетевой дорисовкой кадров (RIFE) и патчингом метаданных.
* 🛠️ **[irgifebry/NoBlur](https://github.com/irgifebry/NoBlur)** — веб-клиент для выравнивания плотности кадров перед выгрузкой в TikTok.

## 🚀 Как TikTok Decoder восстанавливает видео

Инструмент сканирует входной файл с помощью `ffprobe` и автоматически относит его к одной из категорий:

| Тип эксплоита | Механика обхода TikTok | Симптомы на ПК | Алгоритм восстановления |
| :--- | :--- | :--- | :--- |
| **Тип A: Audio Timebase Hack** *(e.g. teat1)* | Звук записан в AAC с timebase `1/22050` при 44.1kHz + 2x видео PTS сдвиг. | Звук заикается каждую секунду, видео длится в 2 раза дольше. | Ресамплинг аудио в 44.1kHz, выправление скорости звука и сжатие PTS видео в 0.5x. |
| **Тип B: Dummy Packet Padding** *(e.g. test2, test3)* | В конец файла дописываются поврежденные/мусорные NAL-пакеты, искусственно раздувающие таймлайн видео до 80–82 секунд при длине звука 14 секунд. | На 14-й секунде плееры на ПК натыкаются на поврежденные пакеты, зависают или отключают звук. Ускорение `setpts` ломало картинку в гипер-ускорение. | Точная отрезка (`-t audio_duration`) битых пакетов с сохранением **1.0x нормальной скорости движения** и плавной картинки 60 FPS. |
| **Тип C: VFR / Timestamp Jitter** | Переменная частота кадров с джиттером таймстеймплов. | Фризы и пропуски кадров в Adobe Premiere / CapCut. | Перекодирование в строгий Constant Frame Rate (CFR 60/120 FPS). |
| **Тип D: Standard** | Обычное видео без хаков метаданных. | Играет нормально. | Чистая нормализация в H.264 MP4. |

## 🛠️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/TikTok-Decoder.git
   cd TikTok-Decoder
   ```
2. Убедитесь, что в системе установлен **[FFmpeg](https://ffmpeg.org/)** (должен быть доступен в PATH).
3. Установите зависимости Python (необязательно, для цветного вывода):
   ```bash
   pip install -r requirements.txt
   ```

## 💻 Использование

### Способ 1: Запуск через Windows Батник (`run.bat`)
* **Drag-and-Drop**: Просто перетащите любой `.mp4` файл или папку прямо на файл `run.bat` мышкой.
* **Интерактивное меню**: Дважды кликните по `run.bat`, чтобы открыть удобное меню:
  * `[1]` Обработать папку по умолчанию `input/` -> `output/`
  * `[2]` Указать свой путь к файлу или папке
  * `[3]` Обработать видео с целевой частотой 120 FPS
  * `[4]` Проверить/установить зависимости

### Способ 2: Запуск через CLI (Python)
* **По умолчанию** (берутся файлы из `input/`, результат кладет в `output/`):
  ```bash
  python main.py
  ```
* **Обработка конкретного файла или папки**:
  ```bash
  python main.py -i "C:\path\to\video.mp4" -o "C:\path\to\output"
  ```
* **Установка целевого FPS (напр. 120 FPS)**:
  ```bash
  python main.py -i input -o output -fps 120
  ```

```
TikTok-Decoder/
├── input/               # Папка для исходных видеофайлов
├── output/              # Папка для отремонтированных готовых MP4
├── src/
│   ├── __init__.py

├── run.bat              # Запуск для Windows (Drag&Drop + Меню)
├── requirements.txt     # Зависимости Python
├── .gitignore           # Правила исключений Git
└── README.md            # Документация проекта
```
