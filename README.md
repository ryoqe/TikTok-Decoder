# 🎬 TikTok Decoder & Repair Tool (v1.2.0)

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![FFmpeg Required](https://img.shields.io/badge/ffmpeg-required-green.svg)](https://ffmpeg.org/)
[![GPU Accelerated](https://img.shields.io/badge/GPU-NVENC%20%7C%20QSV%20%7C%20AMF%20%7C%20MF-brightgreen.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**TikTok Decoder** — это инструмент с графическим десктопным интерфейсом (GUI) и консольной утилитой для анализа и полного восстановления видеофайлов, созданных с помощью обходов кодировщика TikTok («ломание кодировщика», 120 FPS glitch, PTS scaling, `-itsscale`, подмена метаданных MP4).

Такие видео создаются авторами контента для завышения битрейта и обхода сжатия TikTok, но на ПК (в VLC, Premiere, Vegas, CapCut) они лагают, рассинхронизируют звук или содержат битый мусор в конце файла. Инструмент автоматически определит характер повреждений, выправит таймлайн, применит **аппаратное GPU-ускорение** и перекодирует видео в чистый **H.264 MP4 (60/120 FPS)**.

---

## 🔥 Возможности версии v1.2.0

* 🖥️ **Десктопный GUI-интерфейс (`gui.py`)**: Удобное тёмное окно с очередью файлов, индикаторами прогресса, выпадающим списком ручного выбора режима и кнопкой быстрого воспроизведения результата.
* 🛠️ **Ручной перебор режимов (Manual Override)**: Возможность принудительного выбора любого алгоритма починки (Method 1–5), если автоматический анализатор требует ручной корректировки.
* ⚡ **Аппаратное GPU-ускорение (HW Accel)**: Авто-определение NVIDIA NVENC (`h264_nvenc`), Intel QSV (`h264_qsv`), AMD AMF (`h264_amf`) и Windows MediaFoundation (`h264_mf`).
* 🧵 **Многопоточная пакетная обработка**: Параллельная обработка нескольких файлов одновременно (`-j / --jobs`).
* 🔊 **Нормализация звука LUFS**: Опциональное выравнивание громкости аудио под стандарты вещания (`-af loudnorm`).

## 📌 Разбор эксплоитов TikTok

| Режим ремонта | Описание хака метаданных | Симптомы на ПК | Алгоритм восстановления |
| :--- | :--- | :--- | :--- |
| **Method 1: ut0ku** | Подмена метаданных `stts` и `-itsscale` PTS. | Видео лагает или воспроизводитсярывками. | Масштабирование PTS и выравнивание кадров в 60/120 FPS. |
| **Method 2: LuisAlves10** | Дописывание поврежденных NAL-пакетов в конец файла (подмена `mvhd`/`mdhd`). | На 14-й секунде плеер зависает или тушит звук, продолжая крутить таймлайн до 80с. | Точная отрезка (`-t audio_duration`) битых пакетов с сохранением **1.0x естественной скорости**. |
| **Method 3: EditingSource** | Запись 60 FPS кадров при 30 FPS заголовке MP4 контейнера. | Видео выглядит ускоренным в 2x или контейнер показывает 48 секунд с обрывом речи. | Синхронное сжатие PTS видео и звука в 0.5x с выходом на **24 реальные секунды 1.0x движения и полной речи**. |
| **Method 4: NoBlur** | Джиттер таймштампов переменной частоты (VFR). | Фризы и пропуски кадров в редакторах Premiere / Vegas / CapCut. | Перекодирование в строгий Constant Frame Rate (CFR 60/120 FPS). |
| **Method 5: Standard** | Стандартное видео без хаков. | Воспроизводится нормально. | Чистая нормализация в стандартный H.264 MP4. |

## 🚀 Быстрый запуск (Windows)

### Вариант 1: Drag-and-Drop (Просто перетащите файл)
Просто перетащите мышкой любой видеофайл или папку с видео прямо на файл **`run.bat`**.

### Вариант 2: Запуск десктопного GUI окна
Дважды кликните по `run.bat` и выберите пункт `[1]`, либо запустите через Python:
```bash
python gui.py
```

### Вариант 3: Запуск через консоль (CLI)
* **Автоматический ремонт папки `input/`**:
  ```bash
  python main.py -i input -o output --gpu
  ```
* **Принудительный вызов конкретного метода (напр. Method 3)**:
  ```bash
  python main.py -i input -o output -m method3 --gpu
  ```

## 🛠️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ryoqe/TikTok-Decoder.git
   cd TikTok-Decoder
   ```
2. Убедитесь, что в системе установлен **[FFmpeg](https://ffmpeg.org/)** (должен быть доступен в PATH).
3. Установите зависимости Python (для цветного вывода консоли):
   ```bash
   pip install -r requirements.txt
   ```
